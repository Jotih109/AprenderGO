📖 Como Jogar Go (Weiqi / Baduk) - Guia Completo

1. O Objetivo do Jogo

O Go é um jogo de estratégia territorial milenar originado na China. O objetivo principal é cercar mais território livre no tabuleiro do que o adversário.

2. As Liberdades e Captura

Cada pedra colocada possui conexões ortogonais chamadas Liberdades (pontos vazios adjacentes). Quando todas as liberdades de uma pedra ou grupo conectado são preenchidas pelo oponente, o grupo é imediatamente capturado e removido do tabuleiro.

3. Proibição do Suicídio

Não é permitido fazer uma jogada que resulte em 0 liberdades para o próprio grupo, a menos que essa jogada capture imediatamente pedras do adversário.

4. A Regra do Ko (Repetição)

É proibido fazer uma jogada que recrie a mesma posição exata do tabuleiro imediatamente anterior (regra do Ko). O jogador deve jogar em outro lugar primeiro para depois recapturar.

5. Dois Olhos e Vida Incondicional

Um grupo com dois ou mais espaços internos separados (olhos) é imortal, pois o oponente nunca poderá capturá-lo sem cometer suicídio proibido.

6. Fim do Jogo e Pontuação

Quando ambos os jogadores passam consecutivamente, o jogo termina. Os pontos são calculados com base no território cercado + prisioneiros capturados + Komi (compensação para as Brancas por jogarem em segundo lugar, normalmente 6.5 pontos).
